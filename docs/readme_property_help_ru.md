# Пояснения свойств редактора

Краткие русские пояснения в `frontend/src/style-help.js` составлены по документации из локального исходного дерева LVGL 9.6.0:

- `docs/src/common-widget-features/styles/style-properties.mdx` — смысл свойств, единицы, значения по умолчанию;
- `docs/src/main-modules/draw/draw_descriptors.mdx` — прямоугольная тень и тень формы;
- `src/core/lv_obj_draw.c` — применение drop shadow к описателям рисования.

Официальные онлайн-источники: [свойства стилей](https://lvgl.io/docs/open/master/common-widget-features/styles/style-properties), [описатели рисования](https://lvgl.io/docs/open/master/main-modules/draw/draw_descriptors).
Онлайн master может отличаться от закреплённой версии; для реализации сверялись локальные исходники 9.6.0.

`shadow` — тень прямоугольника объекта, `drop_shadow` — тень формы рисунка. У `drop_shadow_opa` по умолчанию 0: для видимости нужно задать непрозрачность, а не только радиус. Тень формы использует временный буфер.

Текущий стенд применяет стиль к Label (`examples/s3_style_lab/main/main.cpp`, селектор 0 в `src/style_runtime.cpp`). Свойства Line/Arc/Image относятся к соответствующим элементам рисования и не создают новые виджеты. Успешный ответ CBOR не доказывает видимый эффект любого свойства на Label. Режим эмулятора не выполняет LVGL.

Пустое поле снимает явное значение: далее действует стиль основы, темы или значение LVGL по умолчанию. Это не всегда означает ноль или отключение эффекта.
