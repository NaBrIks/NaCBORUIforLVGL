# Предложение: читаемая диагностика дерева

Статус: анализ, код не изменять до решения владельца.

Прозрачные тайлы всех уровней одновременно не дают читаемой глубины при прозрачных
компонентах. Изменение цвета/opacity само по себе не устранит наложение. В уменьшенном
MCP-предпросмотре знакоместо 5×6 также теряет читаемость.

Минимальное исправление штатными стилями: для режима разбора дерева задать непрозрачный
нейтральный фон каждого компонента (bg_opa=255), согласованную контрастную палитру,
отключить имеющиеся градиенты и увеличить/разредить цифровой узор. Маски остаются A8;
более сложные изображения, overlay или draw callbacks не требуются. Обычные правила
перекрытия, специфичности стилей и нативной отрисовки всё равно действуют.

Для просмотра реального дизайна с границами предпочтителен outline без цифровой заливки.
Альтернатива, сохраняющая исходную прозрачность: цифровая заливка только выбранной глубины
и outline у остальных; требуется дополнительный выбор глубины, поэтому это не первый
вариант при требовании минимальных изменений.

Проверять следует на сложной композиции с прозрачными контейнерами, несколькими уровнями
и уменьшением кадра, а не только на простом тесте с непрозрачными панелями.


Реализованное уточнение владельца: 16×16 A1, независимые режимы и индивидуальные
глубины; непрозрачная подложка не принималась и не добавлялась. Сдвиг тайлов остаётся
предложением без гарантии отсутствия наложения. Текущее поведение см. в руководстве.
