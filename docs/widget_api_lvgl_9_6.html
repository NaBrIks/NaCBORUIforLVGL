LVGL 9.6.0 · справочник C API

Каталог C-функций и свойств библиотеки LVGL для разработчика. Это не HTTP/MCP API приложения; доступные операции конкретного runtime определяются его capabilities. Отдельная матрица стилей →

Какие ещё наборы есть и как читать таблицы

Стили. Оформление и геометрия, part/state, Flex/Grid. Уже имеют отдельный shared ABI.

Widget properties. Текст, значение, диапазон, options, точки и другие данные класса. Generic Property API покрывает лишь часть C API; требует LV_USE_OBJ_PROPERTY.

Флаги и состояния. Видимость, ввод, скролл, checked/disabled. Состояния также выбирают стили, но не являются их значениями.

Дерево и жизненный цикл. Создание, родители, порядок, удаление, переходы экранов. Это команды, не сохраняемые поля оформления.

События и биндинги. Реакция на clicked/value_changed, подписки и Subjects. В JSON — символы разрешённых действий, без адресов функций.

Ресурсы и службы. Шрифты, изображения, анимации, таймеры, дисплеи и устройства ввода. Аппаратные драйверы в этот каталог не входят.

Область сканирования: публичные include/lvgl/{core, widgets, layouts, display, indev, font, image, fs} и misc/lv_async.h. Стили lv_style_* / lv_obj_*_style_* исключены; геометрические и layout-обёртки оставлены и помечены отдельно по семейству. Это каталог исходников, а не обещание поддержки всех функций в прошивке. Включение функций зависит от lv_conf.h. Числа строк и ссылки закреплены на теге v9.6.0; чтение R/W получено из .setter/.getter, отсутствие записи требует проверки обработчика класса.

Generic API использует собственные внутренние числовые Property ID LVGL. Это не наш сетевой ABI, отправлять их как устойчивые ID между версиями нельзя. Запись LV_PROPERTY_ID2 несёт два типизированных значения.
