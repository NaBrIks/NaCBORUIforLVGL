# Быстрая работа над сайтом

Для настоящего LVGL без платы используйте отдельный [Windows-проигрыватель](readme_windows_player_ru.md). Ниже описан именно браузерный CSS-предпросмотр.

Запуск: `RunSimulator.cmd` в корне или `npm run sim`.
Адрес: http://127.0.0.1:5298/?sim=1.

Меняйте файлы `frontend/src`: Vite обновляет страницу сразу после сохранения.
Сборка и прошивка не нужны. Остановка сервера в консоли: Ctrl+C.

Это эмулятор сайта в браузере: тестовые INFO и задачи, проверка и эхо бинарного CBOR. LVGL и LCD не исполняются, применение прошивкой не подтверждается. Память не имитируется. Режим явно обозначен. Сохранённый адрес платы не используется и не заменяется. Редактор сохраняет изменения стиля как обычно.

Для реальной платы: `npm run dev`, адрес без `?sim=1`, затем подключение к HTTP URL платы.
