# Макет / LVGL в общем редакторе — 09.11.2026

## Результат

В `frontend` добавлены настоящие вкладки Макет / LVGL с EN/RU подписями,
семантикой tablist/tabpanel и переключением стрелками/Home/End. Макет сохраняет
прежние инструменты. LVGL встраивает существующий `NativeViewer`, принимающий
origin общего подключения и режим только чтения. Нового API, сетевого сервера,
рендера или механизма хранения не добавлено.

Выбор страницы и вкладки не посылает show/preview/save или pointer. Явная кнопка
показа и автоприменение при правках сохранены. При смене подключения старые пиксели
очищаются, кадры прежнего поколения отбрасываются, запрос отменяется. Скрытый
просмотр и пауза не запрашивают кадры; размеры и лимиты прежние. Отдельный
интерактивный `/viewer` сохранён; очередь pointer хранит адрес исходного устройства.

## Границы

Windows API отклоняет чужой Origin. Проверено, что выбор второго адреса отправляет
запрос именно туда, очищает прежний кадр и не делает fallback на адрес сайта.
Для положительного Windows-подключения редактор открывается на том же origin,
что API. CORS не ослаблен; успешный cross-origin просмотр не заявляется.
Устройство без `native_view: true` получает пояснение вместо пустого просмотрщика.
MCU/S3 и NTP не изменялись; прошивка с новым кадровым endpoint не заявляется.
