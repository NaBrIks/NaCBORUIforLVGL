# Designer: три режима и каталог точек — 10.11.2026

## Реализовано

Основной режим Direct API использует существующие JS-кодеки внутри BlazorWebView.
Сетевые запросы делает ограниченный same-origin HttpClient приложения. Нет Node
runtime, MCP SDK сервера, отдельного listener или процесса-посредника.
SPLA по-прежнему владеет моделью, историей, очередью и IToolHost.

Native MCP и MCP-прокси — два независимых профиля URL для одного HTTP-клиента SPLA.
Внешний сервер не устанавливается/не запускается. Native Windows MCP — опциональный
PoC на NaWServer (`LVGL_CBOR_NATIVE_MCP`, по умолчанию OFF), 11 реальных инструментов;
JSON-authoring операции остаются в Direct API, не рекламируются в native PoC.

В настройках добавлен каталог именованных точек с устойчивыми ID, отдельными
режимами/адресами, добавлением, копированием и удалением. Старые настройки
переносятся в первую запись. Модель/провайдер общие; ключ остаётся в SecureStorage.
Выбор/сохранение профиля пассивны и требуют явного переподключения. Имя действующей
точки видно в заголовке. Старый кадр и параметры диагностики скрываются при смене
цели; копирование такого кадра запрещено. Кнопки Close/Save всегда видны, поля
прокручиваются внутри панели.

## Исправления по ходу проверки

Передача `X-Project-Revision` через C# callback обязательна для общего ProjectClient.
Redirect запрещён, ответы/запросы ограничены, cookies и ключ модели не пересылаются
на устройство. Scope cancellation и call ID останавливают JS/native HTTP, не только
ожидание JSInterop. ACK уже выполненного save сохраняется при disconnect; неизвестный
результат отменённой мутации явно помечается unconfirmed. Обнаружение layout-debug
и очередь используют общий активный tool host, а не только MCP-сессию.

## Границы

Проверен Windows. Android интерфейс/кодеки общие, но новая телефонная приёмка здесь
не заявляется. S3 в этой итерации не прошивалась и не использовалась для сетевой
проверки; запись точки в локальном каталоге не является подключением к плате.
Внешние LLM-провайдеры этой приёмкой не вызывались. Native MCP PoC имеет собственную
стоимость: сопоставимые Release EXE ON/OFF различались на 223744 байта; это не
измерение MCU Flash/RAM. См. readme_windows_native_mcp_ru.md.

Измерения/скриншоты находятся только в ignored local/. Реальные адреса точек,
ключи и пользовательские проекты не включаются в публичный отчёт.

### Дополнение: каталог подключений

После уточнения владельца каталог вынесен в начало настроек. Проверены три
именованные записи с разными режимами, сохранение/удаление копии, отмена удаления
и восстановление всех записей/выбора после перезапуска MAUI. При смене цели до
переподключения старый кадр действительно отсутствует в UI, имя прежней точки
не обозначается как новое действующее соединение. Модель и ключ остались общими.
Footer Close/Save видим без прокрутки; поля прокручиваются в своей области.
Финальная сборка — 0 предупреждений/ошибок; общий JS suite 366/366, Core suite PASS.

### Дополнение: отдельные вкладки Model / Devices

Windows MAUI собрана без предупреждений и ошибок. Через настоящий WebView проверены
две вкладки и независимые черновики: сохранение Devices не уничтожает несохранённую
модель. Сохранение модели не снимает pending Reconnect после смены устройства.
До явного Connect старый кадр отсутствует, копирование заблокировано. Финально
восстановлен Windows Direct API, показан реальный кадр; чат и очередь пусты.
Ключ не извлекался в журнал. Передача Retry-After через native HTTP bridge проверена
наличием в allowlist. Общий JS suite обновлён: 372/372 PASS.
