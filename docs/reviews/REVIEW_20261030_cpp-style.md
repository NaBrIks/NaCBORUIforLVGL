# Единое оформление C/C++: Uncrustify

Дата: 2026-10-30. Прямое решение владельца: профиль NaWServer,
Uncrustify **0.83.0_f**, собственные поддерживаемые C/C++ файлы.
Форматирование выделено в отдельный коммит после функциональных и лицензионных
изменений. Поведение, зависимости и номера wire ABI не менялись.

## Профиль и область

- Корневой `uncrustify.cfg` сохраняет профиль NaWServer. SHA256 опубликованного
  Git blob с LF:
  `3be39942f18335d9a89956cc2c710de872f3372db5b3c8e172f4c66c8cc2a457`.
  У проверенной рабочей копии с CRLF SHA256:
  `5002ec0eef0aab6e8ca441655ea4e30da2f9469b552b75d6a10ab53400ab8f21`.
  Разница относится только к переводам строк, настройки профиля одинаковы.
- Адаптированы [английская](../../agents/code_style.md) и
  [русская](../../agents/code_style.ru.md) инструкции; команды соответствуют
  действительному `tools/format_cpp.ps1`, машинных путей в Git нет.
- Список строится из существующих Git-tracked файлов: **93 файла**, из них
  **87 изменены**. Поддерживаются Check/Apply/List и явный путь к программе.
- Исключены vendor/third_party/managed_components/node_modules/.pio/fonts/generated/SIG
  на любом уровне, контракты/каталоги генераторов, assets.hpp, sample_image.hpp
  и сторонняя адаптация LilyGO board.cpp. Vue/JS/JSON и третьи библиотеки не
  форматировались. SPDX/CC0 и подтверждённые notices сохранены.
- Прежняя `.clang-format` не активна; локальная архивная копия ignored.

## Проверки

Два Apply приведены к Check без отличий. Третий Apply проверен SHA256 каждого
из 93 файлов: **0 изменений**, Check: **0 ошибок**. Локальное сравнение C++
токенов 87 изменённых файлов не нашло отличий после исключения комментариев,
пробелов и эквивалентного разделения закрывающих `>>` вложенных шаблонов.
Это вспомогательная проверка; сборки и регрессионные сценарии проверяются отдельно.

После форматирования пройдены:

- полный native-набор с официальными LVGL 9.6.0 / TinyCBOR 0.6.1;
- Windows Release с теми же официальными зависимостями;
- скрытая Windows-регрессия: 12 стандартных типов, четыре схемы, события,
  writeback, JSON/CBOR, ошибочные загрузки, вложенность и shutdown;
- настоящий Win32 resize: пять размеров, все четыре страницы, границы каждого
  компонента, отсутствие обрезки/лишнего scroll, постоянный экземпляр и история;
- реальные CPU (32 логических процессора), RAM и два GPU: накопление 32 отсчётов
  вне страницы, CBOR-вход, схемы и границы. Просмотрены LVGL-снимки System
  800×480 и 1600×900 с отдельными Flex-блоками CPU/RAM/GPU/GPU memory;
- JS **311/311**, MCP **8/8**, contract:check, production build редактора;
- ноль повреждённых локальных Markdown-целей и ноль совпадений проверенных
  шаблонов секретов/локальных идентификаторов в дереве и истории. Последнее
  является проверкой определённых шаблонов, а не универсальной гарантией.

Платы, их прошивки, разделы и файлы не затрагивались. Видимое приложение владельца
не перезапускалось; проверки используют скрытые Windows-экземпляры без ввода.
