# NaBrIks: документация, воспроизводимость и перенос

Дата: 2026-10-30. По поручению владельца сохраняется история NaCBORUIforLVGL,
включаются завершённые изменения Windows responsive/Flex/ScreenViewport и
документация. Удаление истории задано другому проекту, не этой библиотеке.

## Подготовка и проверки

- Корневые имена приведены к `Readme.md` / `Readme.ru.md` через промежуточные
  Git-переименования. Английский и русский обзоры согласованы: API, архитектура,
  зависимости, clean checkout, ограничения, примеры и лицензии.
- `examples/common` с Appearance/DemoData, публичные заголовки и JS-кодеки входят
  в дерево исходников. Они не зависят от локальных артефактов основного приложения.
- Native CMake и `tools/test_native.ps1` принимают явные пути к LVGL/TinyCBOR;
  подготовленный S3 managed_components больше не обязателен для host-тестов.
- Проверен чистый экспорт staged Git tree без SDK/соседних репозиториев/сборок.
  `npm ci`, **311 JS-тестов**, `contract:check`, production build — PASS.
  Отдельные install/tests MCP — **8/8 PASS**.
- Native suite из чистого дерева с официальными LVGL 9.6.0 и TinyCBOR 0.6.1 —
  PASS. Windows Release собрана с заново скачанными официальными исходниками;
  regression, resize всех страниц и реальные CPU/RAM/два GPU — PASS.
- Теги зависимостей проверены через удалённые refs: LVGL
  `80ca777e37a2b176770726a02e07a6fb79ef0b39`, TinyCBOR
  `1e8296f94e40c6ac976d4c5a7b1db7f45978a83f`.

Чистая проверка обнаружила разницу EOL в Git blobs и рабочем дереве. Добавлена
`.gitattributes` с LF для текста. Screen v3 сохраняет исторический fingerprint
`88b890b59be1a2bc499022a2e23870779778bf58dff3430f0ef8f091ae9c557a` явной
канонизацией CRLF при расчёте этого опубликованного hash. Отдельный тест проверяет
LF/CRLF и чувствительность к другим изменениям. Fingerprints/номера wire ABI
не изменились, существующие скомпилированные проекты не инвалидируются.

## Лицензии и приватность

Ядро/кодеки/MCP/common/Windows/LilyGO — MIT. У frontend/RGB сохранена имеющаяся
GPL-3.0-only provenance; Tabler/LilyGO и прочие notices сохранены, шрифты ОС не
скопированы. Лицензия внешнего сервера относится к выбранной его ревизии и не
перелицензирует адаптированные файлы здесь. Перенос и история не снимают notices.
Добровольный донат не меняет лицензию; платёжная ссылка не создавалась.

В 530 исходных текстовых файлах и существующей истории не найдено совпадений с
проверенными шаблонами GitHub/AWS/private-key секретов и известных локальных
адресов/идентификаторов. Это проверка определённых шаблонов, не универсальная
гарантия. SDK, firmware, журналы, фотографии и private config остаются ignored.
Все локальные Markdown-цели проверены с учётом регистра; ссылки на непубликуемые
local-артефакты заменены пояснениями. Проверены 39 внешних Markdown URL; приватные
GitHub-ресурсы проверяются аутентифицированным API, а не HTTP 404 без авторизации.
Историческая ссылка на прежнее имя сервера заменена действующей.

Исходный GitHub repo перед переносом подтверждён как private, текущая учётная
запись имеет admin, в NaBrIks подтверждена роль admin. Фактический перенос и
конечные refs проверяются отдельно; приватность должна сохраниться.
Платы, их разделы и общая FS в этой задаче не менялись. Новая аппаратная приёмка
не заявляется; исходные доказательства и результаты сборок находятся в ignored local/.
