# Журнал агента, границы дисплея и возврат к базе

Проверка 08.11.2026. Добавлены вкладки Лог / Предпросмотр экрана под prompt.
Данные журнала идут тем же Node bridge → HostAgent → readonly DataRegistry → CBOR
WS; нового listener или параллельного API нет. До 48 записей, до 1024 UTF-8 байт
на запись и 12 KiB JSON суммарно. Старые записи вытесняются. Публикуются имя и
цель инструмента, результат, ошибка и ответ; аргументы/проект целиком, картинки
и ключ не записываются. Конфигурация DPAPI журнал не сохраняет.

Домик показывает entry сохранённого проекта без reset/save. Отдельная кнопка
в настройках выполняет подтверждённый reset с revision, затем показывает базовый
entry. База доступна только для чтения; подтверждение и reset проверены только
на временном тестовом проекте. В работе владельца данные не сбрасывались.

При исследовании сообщения о пропавшей раскладке сохранённые screens/styles
совпадали с базой, changed=false. Агент открыл отдельный canvas вместо корневой
оболочки; общий экран возвращён штатным show без сохранения/сброса. Дополнены
инструкции агента: учитывать контейнерную навигацию и не объявлять пустые events
без action/write/navigate.
