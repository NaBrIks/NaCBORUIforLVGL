# Окончательное название проекта

2026-10-23 владелец выбрал **NaCBORUIforLVGL** вместо LVGL LiveCBOR.
Описание: `CBOR-based UI definitions for LVGL`.

Обновлены заголовки браузера и редактора, стартовая надпись примера, актуальные README/руководства, имя MCP-сервера и пример подключения, npm workspace и описание. Исторические отчёты сохраняют прежнее название. Технические include, namespace ядра, имена пакетов, ключи черновиков и ABI сохранены.

Проверены production-сборка редактора, 8 тестов MCP и контракты. В браузерном симуляторе новое название отображается в шапке и заголовке вкладки. Прошивка устройства и публикация не выполнялись.
