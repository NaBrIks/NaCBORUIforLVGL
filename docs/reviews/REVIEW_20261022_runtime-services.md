# Проверка общих сервисов, кодеков и модульного редактора

Дата: 2026-10-22. Рабочая папка: ../lvgl-cbor.

Реализованы возможности подключённой прошивки, общий StyleService, проверяющие двусторонние кодеки, общая проверка документа и разделение App.vue. Подробности и границы: [руководство](../readme_runtime_services.ru.md), [ADR](../adr/ADR_20261022_lvgl-cbor_capabilities-style-service-roundtrip.md).

Native services проверяет разделение static/dynamic, общий глобальный стиль в обоих исполнителях, стабильный адрес при замене, редактирование именованной области действующего экрана, release при unload и внешнем DELETE, владение перенесённым узлом, явный кэш, защиту удерживаемой области от очистки и snapshot массивов Grid после замены источника.

JS проверяет отмену прежней сессии при изменении адреса, игнорирование старого HTTP-ответа, обновление capabilities при смене boot ID, видимость INFO старой прошивки при запрете команд без capabilities, чужие/неправильные ACK и парные преобразователи значений.

Снимок браузера: `../../local/modular-editor-verified.png`. Проверенный адрес `http://127.0.0.1:5298/?sim=1` доступен в режиме эмуляции.
