# NaWServer, лицензии и подготовка исходного коммита

> Результаты MCP в этом отчёте относятся к прежней реализации.
> Актуальные способы подключения описаны в [руководстве MCP](../readme_mcp_ru.md).


Дата: 2026-10-23.

## Выполнено

- Демка использует компонент **NaWServer**, include `<NaWServer/...>`, namespace `NaWServer` и класс `NaWServer::Server` вместо прежнего `IDFWebServer`.
- HTTP-адаптеры проекта и данных перенесены в `integrations/nawserver`; маршруты, схемы, очереди и семантика API не менялись.
- `EXTRA_COMPONENT_DIRS` и пути PlatformIO в двух сборочных скриптах указывают на соседнюю папку `NaWServer`. Возможность явно задать `CoreDir` сохранена.
- Самостоятельные ядро, кодеки и MCP имеют MIT; фронтенд и аппаратный пример сохраняют GPL-3.0-only. Добавлены корневые LICENSE, LICENSES.md и метаданные npm. Версии зависимостей не менялись; ESP-IDF обновил manifest_hash в lock-файле при смене серверного компонента.
- Основной README и описание npm написаны на английском; `readme.ru.md` содержит русский обзор. Указана приватность серверной зависимости и необходимость доступа для сборки демки.
- `.gitignore` дополнен приватными ключами, локальными заголовками настроек, Python-окружениями, кэшами и выходами CMake. Проверены 19 исключаемых путей и 9 сохраняемых исходных файлов; отслеживаемых файлов, совпадающих с ignore-правилами, нет.

## Почему демка GPL

NaWServer объявляет `GPL-3.0-only` в своём `idf_component.yml`; сервер включается в общую прошивку. Кроме того, код платы/дисплея и оболочки редактора адаптирован из GPL-проекта ESP32-yaidfws. Переименование зависимости не меняет эти условия. MIT самостоятельного ядра не отменяет GPL для распространяемой объединённой демки. Исходные уведомления и лицензии сохранены; исторические отчёты и атрибуции продолжают использовать прежнее имя источника.

## Проверки

Изменения предназначены для одного начального коммита. Удалённый репозиторий не создавался; публикация и прошивка устройства не выполнялись. Фактические журналы сборки и локальные настройки остаются в игнорируемом хранилище.
