# Проверка первого MVP экранов и компонентов

Дата: 2026-10-22. Проект: `../lvgl-cbor`. LVGL 9.6.0. Это проверка исходников, браузера, нативного LVGL и сборки ESP32-S3; новую прошивку на плату не заливали.

## Что проверено

| Проверка | Результат |
|---|---|
| `npm test` | 181 тест, все пройдены; включая screen codec и неизменность ABI |
| `tools/test_native.ps1` | Прежний StyleRuntime и новый ScreenRuntime пройдены на настоящем LVGL/TinyCBOR |
| `npm run build` | Vue/Vite production build успешен |
| `node tools/pack_assets.mjs` | Собранные ресурсы сайта подготовлены для стенда |
| `tools/build_s3.ps1` | Успешная сборка ESP32-S3; последняя проверка 49.08 с |
| Браузер `http://127.0.0.1:5298/?sim=1` | MVP Flex открыт, дерево и три карточки видны; компиляция CBOR успешна, 1510 байт |
| Property API | В native оба макроса равны 0; в S3 `CONFIG_LV_USE_OBJ_PROPERTY` выключен, запрет NAME дополнительно проверяется C++ `#error` |

Нативные проверки покрывают ручное размещение, Flex/grow/column, Grid/FR/span/stretch, вложенные контейнеры, общие стили и состояния, параметры виджетов, сохранность заимствованных points/tracks после освобождения CBOR, отказ без замены прежнего дерева и уничтожение.

Одинаковое описание компонента смонтировано дважды с независимыми ID и состоянием. Вложенный `mount()` другого владельца вызывается из настоящего `LV_EVENT_CHILD_CREATED`; рекурсивная замена того же владельца отклоняется с `runtime_busy`. Выполнены 50 повторных замен, удаление внешнего родителя, восстановление прежнего самостоятельного экрана и сценарий уже удалённого fallback.

Ошибочные пакеты проверяют обрезание CBOR, неизвестные opcode/signature/ABI/ресурсы, повторные ID, непустые bindings, конфликт флагов, диапазоны, глубину и недопустимые Grid/subgrid. Это не проверка исчерпания heap: восстановление после фатального OOM LVGL/STL пока не гарантируется.

## Артефакт S3

- `examples/s3_style_lab/.pio/build/s3/firmware.bin`: 1 419 920 байт.
- SHA-256: `2DEC9A13A6B4CA7870CC9A195C84C71BE99526B896BA8877A57B163E487184F0`.
- Статическая RAM по отчёту линкера: 140 160 / 327 680 байт, 42.8%.
- Flash по отчёту линкера: 1 419 520 / 5 242 880 байт, 27.1%.
- Это показатели полной прошивки стенда, а не отдельного исполнителя и не измерение heap во время работы.

PlatformIO 6.10 не отслеживал root CMakeLists компонента из EXTRA_COMPONENT_DIRS. Build helper теперь сбрасывает только configure cache примера, если список исходников компонента новее. Новые исходники попали в окончательную сборку. LVGL 9.6 выдаёт два предупреждения deprecated для совместимых `lv_obj_add_flag/remove_flag`; они не подавлялись.

## Границы результата

На МК добавлены ядро, числовые таблицы вызовов и `/screen-ws` с ограниченной очередью; LVGL вызывается в UI-task. Транспорт стенда допускает пакет до 3584 байт. Реальные WS ACK, расход динамической памяти и отображение LCD этой прошивки ещё не проверялись.

Симулятор сайта выполняет CSS-приближение и компиляцию, а не LVGL. Снимок проверки: `../../local/screen-mvp-preview.png`. Пакеты/примеры и карта файлов описаны в [руководстве](../readme_screen_runtime.ru.md).
