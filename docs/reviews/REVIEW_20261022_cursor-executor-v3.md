# Проверка курсорного исполнителя экранов v3

Дата: 2026-10-22. Работа ограничена lvgl-cbor. Плата не прошивалась; физический LCD этой сборкой не проверялся.

## Реализовано

- Экранный контракт v3: 0 создаёт компонент, 1…255 — общие операции, 256…65535 — локальные методы компонента.
- При создании выбираются фабрика и обработчик. Стандартные методы вызываются через switch, без общих массивов сигнатур и без Method/WidgetMethod.
- Вложенные массивы читаются по курсору. Есть возврат к родительским командам после ребёнка, переход к соседу и пустое тело. Дерева команд в памяти МК нет; дерево владения остаётся для cleanup/lookup.
- Стили передаются отдельным блоком в существующий исполнитель ABI v2. Его контракт и SHA не изменены.
- Runtime-регистрация сохранена; тип расширения можно разрешить по числу или имени. ABI проверяется при создании, регистрация удерживается живым экземпляром.
- Сохранены исходный декларативный JSON, компиляторная проверка значений/порядка, Button.text roundtrip и общий сервис стилей.
- Обновлён адаптер предпросмотра S3, который ранее читал поля старого wire-дерева.

## Границы результата

Старые пакеты экранов требуют перекомпиляции; стиль остаётся ABI v2. Прошивка содержит согласованные встроенные web-assets, но на устройство не загружена. Сборка выдаёт существующие deprecation warnings LVGL для lv_obj_add_flag/lv_obj_remove_flag; это не ошибки сборки. Замеров скорости исполнения не проводилось.

Декларативный decode сохраняет программы, произведённые компилятором. Произвольные программы с повторными setter-ами или командами родителя после детей исполняются нативно, но отклоняются декларативным decode, если старый JSON не может выразить их порядок. Полный визуальный редактор произвольных нативных расширений не добавлялся.
