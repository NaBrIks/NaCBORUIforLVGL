# Нативные спидометр и радар — проверка 2026-10-22

Уточнение владельца: сложный пользовательский компонент должен показывать собственную нетривиальную графику. Вместо двух первых составных панелей реализованы `lab:speedometer` и `lab:radar`. Простой `lab:signal` сохранён. [Первая версия](REVIEW_20261022_native-components.md) остаётся исторической.

## Реальная графика на МК

- `speedometer.hpp`: собственный callback `LV_EVENT_DRAW_MAIN`, шкала 270°, 61 риска, 13 числовых подписей, зелёная/красная зоны, треугольная стрелка, ступица и цифровое показание. Методы задают диапазон, показание/единицу и начало красной зоны.
- `radar.hpp`: собственная полярная сетка, круги дальности, компас, вращающийся луч со следом и контакты с послесвечением. Массив 0…8 контактов читается непосредственно из вложенного CBOR. Таймер экземпляра с периодом 100 мс меняет угол на 3°; `running` управляет паузой. DELETE удаляет таймер.
- `drawing.hpp`: общие примитивы LVGL Draw. Эти два компонента не состоят из дочерних стандартных виджетов; PNG/SVG и кадры с ПК не используются. Браузер показывает рамку и формы по каталогу платы.

Имена/ID/ABI: `lab:signal` / 256 / `signal-1`; `lab:speedometer` / 259 / `speedometer-1`; `lab:radar` / 260 / `radar-1`. Старые ID 257 и 258 не переиспользованы. Общие экранный v3 и стилевой v2 ABI не менялись.

## Проверки

`npm test`: **237 / 237**. Полный нативный набор LVGL/TinyCBOR прошёл. Новый графический тест создаёт настоящий RGB565-буфер 800×480, проверяет наличие разных цветов в областях приборов и изменение пикселей при повороте луча. Дополнительно проверены скаляр/кортеж/массив контактов, 100 замен, lifetime текста, удаление дерева/таймера и runtime-регистрация. Растр из самого LVGL сохранён в `local/native-graphics-raster.png`.

На S3 выполнены **24 варианта + финальный экран** с изменением скорости 0…230, красной зоны, состояния индикатора, массива 0…8 целей, режима и начального азимута радара. Перезапусков не было: boot `s3-6b663d53`. Это проверка нативной реализации до последнего обновления только браузерных форм; артефакт `local/native-graphics-hardware-exercise.json`.

В финальном встроенном редакторе проверены компактная таблица контактов, добавление пятого контакта, редактирование и удаление, отклонение азимута 360°, остановка и запуск радара, подтверждение применения. ACK: **5 узлов описания, 5 стилей, 42 операции**, границы 800×480. Консоль браузера без warnings/errors.

Отдельно воспроизведён reload после исчезновения старого нативного типа из capabilities. Старые черновики сохранены; невалидный для текущей платы документ не становится исполняемым. После замены его новым предупреждение очищается. Каталог, типы параметров и методы взяты из живой S3.

## Финальная прошивка и физическая проверка

COMx, ESP32-S3 rev0.2, MAC `02:00:00:00:00:01`, Flash 16 MB / PSRAM 8 MB повторно определены перед записью. Живая таблица разделов совпала со сборкой. Записано только приложение с `0x10000`, hash подтверждён esptool.

- BIN: **1 486 800 B**.
- SHA-256: `b88c021ea16c1173de71b24dd4ae0823c8f1fdced4facc836c6e6596db2b7626`.
- PlatformIO Flash: **1 486 392 B**, статическая RAM: **141 144 B**.
- Встроенные 8 web-файлов: **458 112 B** исходных, **160 289 B** gzip во Flash. Все 8 побайтно совпали с `frontend/dist`.
- Финальные IP / boot: `192.0.2.1` / `s3-d2f23ede`.

По сравнению с первой панельной версией новый BIN больше на **7 600 B**; статическая RAM не изменилась. Это размеры сборок, не измерение динамической памяти фабрик.

На LCD оставлены RUN, спидометр **87 km/h** и работающий радар с четырьмя целями. USB-камера сняла два разных положения луча: `local/native-graphics-lcd-1.jpg` и `local/native-graphics-lcd.jpg`, оба 1280×720. Содержимое физического LCD проверено, вращение видно по разным углам в двух снимках. Исходный режим экспозиции камеры восстановлен. Фотографии не ретушировались.

Доступны файлы импорта `local/native-widget-fixtures/demo.json` и `demo.cbor`; руководство [readme_native_components.ru.md](../readme_native_components.ru.md). Изменения не закоммичены.
