# S3: новый TCP HTTP/WS стек и полный образ

Дата: 2026-10-28. Проверена реальная Waveshare ESP32-S3-Touch-LCD-7 Rev1.2,
LVGL 9.6.0, ESP-IDF 5.5.6, Espressif32 8.0.0. Соседняя рабочая копия NaWServer
содержала локальные доработки поверх 632dafd; они не изменялись этим проектом.
Результат относится к этой проверенной копии, а не к неизменённому remote-коммиту.
Оригинальные журналы, идентификаторы, адреса и снимки остаются в ignored `local/`.

## Изменение и обнаруженный сбой

Приложение использует HttpServer + TcpHttpBackend + IdfTransport вместо прежней
оболочки Server/native HTTPD. HTTP/WS маршруты, JSON/CBOR-кодеки, ABI и очередь
UI сохранены. Статические gzip assets отправляются через sendImmutable;
динамические снимки используют обычный send.

На первом образе с HTTP worker 6144 Б повторные запросы INFO/capabilities
приводили к reset reason 5 (interrupt watchdog), резерв стека был около 868 Б.
Читаемый panic backtrace по доступной UART-связи получить не удалось;
точное место остановки по трассе не установлено.

После увеличения прикладного HTTP worker до 12288 Б те же проверки проходят.
High-water reserve после нагрузки — 5828 Б: измеренный расход около 6460 Б
превышает прежние 6144 Б. Watchdog не отключался, его таймаут не увеличивался.
Это обоснование профиля приложения, не универсальный минимум NaWServer.

## Прошивка

По прямому указанию владельца прежний проект не архивировался. После проверки
chip/MAC записаны и проверены по хешам bootloader (0x0), таблица (0x8000),
приложение (0x10000) и SPIFFS 4 МиБ (0xC00000). NVS/PHY не стирались.

Приложение: 1945744 Б, SHA256
`ec120df3862b49c49440e41511d3fa799ce9dd102a71e88e4e07362c07507ee0`.
Линкер: static RAM 84436 Б, Flash 1945345 Б. Это размеры сборки, не свободная RAM.
Для диагностики использован локальный ignored sdkconfig с UART0 console;
обычные defaults сохраняют выбранную в проекте USB console.

Стартовый проект имеет четыре страницы: dashboard, radar, trip и shell.
Entry — shell, со статусбаром, контейнером и тремя нижними кнопками.
Дочерние страницы сохраняют проектные размеры: содержимое dashboard выше
области контейнера и прокручивается. Полная прошивка задаёт проектный SPIFFS;
последующие диагностические проверки не сохраняли проект.
