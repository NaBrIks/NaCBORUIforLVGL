# Приёмка двух Windows-демок, графики и помощника

> Результаты MCP в этом отчёте относятся к прежней реализации.
> Актуальные способы подключения описаны в [руководстве MCP](../readme_mcp.ru.md).


Дата: 2026-11-08. Оба профиля используют один C++ runtime и NaWServer.
Платы, NTP и чужие процессы не изменялись. Коммит/публикация не выполнялись.

- System: authored topology 32/2 удалена. Реальные размеры получаются из
  DataRegistry/DXGI/PDH; недоступные counters остаются пропусками. Проверено
  соответствие реально обнаруженной топологии без закрепления моделей
  оборудования в публичных исходниках проекта.
- Graphics: независимый профиль без SystemMetrics. Пять страниц: растровая,
  векторная, пульт, пустой MCP-холст, настройки. Все 19 образцов имеют одну
  шахматную подложку. BIN/RAW: 0 отличий; GIF меняется при остановленном
  генераторе. Прозрачные углы PNG/ARGB/A8 показывают подложку.
- Собственный цветной SVG, четыре схемы и подписи проверены настоящими
  нативными снимками. Декодеры и Vector API — реальные LVGL.
- Пульт представлен данными JSON/CBOR. Общий polygon_button ничего не знает
  о направлениях/клавишах пульта. Рисунок и ADV_HITTEST используют один
  normalized even-odd контур. Пять пустых/внешних точек не вызывают событий;
  внутри работает штатный PRESSED/click/action/binding. MCP меняет тот же
  узел с сектора на треугольник — активная область меняется вместе с фигурой
  без сборки. Обводка фокуса подтверждена пикселями.
- По замечанию владельца стрелки заменены отдельными геометрическими
  треугольниками. Они некликабельны и пропускаются keyboard focus. У секторов
  равномерный зазор 6 px, мягкие углы; центральная OK 132 px, боковые рокеры
  разделены зазором 4 px. Убрана отдельная декоративная дуга. Последняя
  правка preview/save/show выполнена реальным MCP на работающем приложении,
  без изменения EXE или перезапуска. Счётчик данных сохранился.
- Сайт graphics раздаётся NaWServer: online Viewer показывает настоящий BMP
  кадр LVGL и передаёт отдельный pointer input с watchdog. Нативный тест
  проверяет реальный hit-test, pixels/bindings, 2 Мпикселя до allocation,
  413 и восстановление после уменьшения окна. Это не offline WASM renderer.
- Изолированный headless Chrome загрузил /viewer, получил реальные 1280×800
  кадры и AssistantPanel. Список моделей получен по кнопке из публичного
  OpenRouter API; платных completion-вызовов не было. Успешное сохранение,
  ошибка endpoint и восстановление не меняли геометрию панели или scroll.
- Помощник проверен mock-провайдером с настоящим MCP/NaWServer/ProjectService:
  7 tool calls за 5 model rounds создали и сохранили кнопку на холсте,
  исполнили событие; реальный LVGL счётчик показал 7.
- Настройки endpoint/model/key шифруются настоящим Windows DPAPI. Два
  независимых процесса проверили Unicode/tamper, отсутствие plaintext в
  файле/sidecars/публичных ответах, восстановление после перезапуска.
  Ошибочный save даёт completion.ok=false и сохраняет прежний ciphertext.

Проверки: JavaScript 336/336; MCP unit 9/9; contract:check PASS; frontend
production build PASS. Отдельные native тесты gallery, viewer, assistant,
host-settings, стандартных компонентов и resize — PASS. Сборка Release
обновлена, оба приложения запущены. Локальные снимки/измерения находятся в
ignored local. Прямое диагностическое чтение один раз встретило закрытый
повторно используемый keep-alive socket; повторное безопасное GET с отдельным
соединением прошло. Автоматических повторов изменяющих операций не добавляли.
