# Переход на LVGL 9.6.0

2026-10-21. Официальный [релиз v9.6.0](https://github.com/lvgl/lvgl/releases/tag/v9.6.0), опубликованный 16 сентября. Предыдущие отчёты с LVGL 9.4 — исторические результаты, их измерения не переименованы.

## Исходники, таблица и ABI

- Managed component закреплён на 9.6.0; `dependencies.lock` обновлён. Официальные исходники компонента не патчились.
- Генератор теперь читает публичные заголовки из `include/lvgl`; тела составных style-setter функций — из `src/misc/lv_style.c`.
- [Новая матрица](../style_matrix_lvgl_9_6.html): 129 свойств, 303 функции, 75 групп сигнатур. По семействам: shared 138, local 138, helper 21, generic 6. Вкладки, объединённые заголовки, колонка количества параметров и C-сигнатуры сохранены.
- Добавлены blur radius/backdrop/quality, drop-shadow radius/offset X/Y/color/opacity/quality и text-leading-trim. Поля и enum-списки редактора генерируются по новому контракту.
- Все прежние 128 shared-индексов и 26 сигнатур сохранены. Новые методы 128–137, сигнатуры 26–27. Shared-номера в HTML сверены с wire-контрактом. Старые enum-константы не изменились.
- [ADR об ABI](../adr/ADR_20261021_lvgl-cbor_append-only-style-abi.md): новые номера только в конец, исчезнувшие записи остаются retired; номера не переиспользуются. Генератор и тесты проверяют фиксированный реестр. Правило добавлено в документацию будущих биндингов.
- SHA256 контракта: `b475331f48a550a852c487edd9c6df9ccbaf8d3e088973b3f1d8577205f6d16d`.

Окончательный firmware.bin: 1 351 472 байта, SHA256 `f122c602ac2444b91b00c3a2335c65ce92ac05f897ef384a52ac3f591f216430`. NVS и таблица разделов не перезаписывались. Для сборки добавлен `tools/build_s3.ps1`: менеджер компонентов 2.5.2 установлен в локальный каталог проекта, поскольку старая версия не разбирает `$CONFIG{...}` из нового манифеста. Пакеты Python соседнего проекта не обновлялись. Устаревшие настройки color depth/memory/assert заменены настройками 9.6.

Встроенный браузер запретил просмотр `file://` новой HTML-таблицы. Её структура, покрытие API и совпадение shared-сигнатур проверены программно; визуальная проверка именно таблицы 9.6 не выполнена. Веб-редактор проверен в браузере, включая новые enum-поля. Снимок проверки хранится вне публичной документации.

Новые графические эффекты не проверялись оптически на LCD: нативный тест подтверждает запись/чтение свойств, а не отрисовку каждого эффекта на каждом виджете. Ресурсные ограничения демки прежние. Биндинги остаются проектированием. Стенд всё ещё требует точного совпадения хеша контракта браузера и МК.
