> Актуальные способы подключения описаны в [руководстве MCP](../readme_mcp_ru.md).


Дата: 2026-10-23.

## Название и совместимость

Принятое название — **LVGL LiveCBOR**, имя репозитория — `lvgl-livecbor`.
Обновлены заголовок веб-страницы, шапка редактора, стартовая надпись аппаратного примера, README, актуальные руководства, имя рабочего npm-проекта, MCP server metadata и пример конфигурации клиента.

Технические имена `lvgl_cbor`, `LVGL_CBOR_*`, `@lvgl-cbor/*`, форматы документов и ключи localStorage сохранены. Черновики не требуют миграции. Исторические ADR и отчёты сохраняют исходные термины. ESP-IDF-пример определяет имя компонента по папке checkout: клонирование как `lvgl-livecbor` не требует ручного изменения зависимостей CMake. Локальную папку можно назвать иначе.

## Состав публикации

Проверены отслеживаемые файлы: частные сетевые адреса, персональные пути, распространённые форматы ключей, URL с credentials и присваивания секретов. Единственное срабатывание URL — намеренный отрицательный тест с вымышленными `user:secret`. Реальные настройки Wi-Fi, журналы, прошивки, сборки и исходные локальные снимки исключены из Git. Крупнейшие отслеживаемые файлы — версионируемые справочники LVGL, необходимые для документации; лицензии, lock-файлы, ABI и сведения о происхождении сохранены.

По решению владельца подготовлен один новый начальный коммит вместо прежней истории. Встречающиеся в старых отчётах хеши относятся к прежним локальным проверкам и в новой истории не разрешаются. Резервная копия прежнего Git хранится только в игнорируемом локальном каталоге. Публикация и создание удалённого репозитория не выполнялись.

По последующему решению владельца от 2026-10-23 самостоятельное ядро, кодеки и MCP лицензированы под MIT; области действия описаны в LICENSES.md. Основной README переведён на английский, русский сохранён в readme.ru.md. Существующие GPL-3.0-only уведомления адаптированных примера и фронтенда сохранены. Проверка секретов является проверкой содержимого и шаблонов, а не гарантией отсутствия любого возможного секрета.
