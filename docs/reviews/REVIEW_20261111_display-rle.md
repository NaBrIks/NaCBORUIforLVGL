# Приёмка LVF2 и RLE, 11.11.2026

Waveshare 7″ S3, RGB565, 800×480, два буфера, режим передачи Dirty. Измерения
сделаны через NaWServer на странице TPMS/GPS. Размеры ниже включают заголовки
LVF2 и исключают HTTP/TCP. Время — от запроса до завершения HTTP-потока.
CPU — доля времени одного ядра по счётчикам FreeRTOS задачи HTTP. Для
обновлений это окно из трёх запросов с двумя паузами по 400 мс. Три измерения
сведены по медиане времени. Прошивка записана в активный OTA-слот приложения.

| LVGL | Кодирование | Первый кадр, КиБ / с / CPU HTTP | Обновление, КиБ / с / CPU HTTP |
|---|---|---:|---:|
| FULL | RAW | 757,5 / 3,87 / 6,47% | 757,5 / 3,89 / 5,60% |
| FULL | RLE, буфер | 90,5 / 0,75 / 18,75% | 90,6 / 0,70 / 14,45% |
| FULL | RLE, поток | 90,4 / 0,68 / 19,88% | 90,6 / 0,71 / 14,00% |
| DIRECT | RAW | 757,5 / 3,79 / 5,93% | 187,1 / 1,09 / 4,65% |
| DIRECT | RLE, буфер | 90,5 / 0,78 / 18,22% | 20,9 / 0,39 / 6,23% |
| DIRECT | RLE, поток | 90,5 / 0,75 / 17,72% | 20,7 / 0,37 / 6,21% |

Задача LVGL в окне первого кадра занимала 73,7–74,6% одного ядра в FULL
и 59,2–61,9% в DIRECT. Свободная внутренняя память составляла около 69 КиБ.
Выключение буфера порции убирает выделение 4096 байт. При недоступности этого
выделения прошивка журналирует отказ и использует потоковый RLE. Буфер всего
кадра в транспорте отсутствует.

В основной матрице часы после перезапуска ещё не успели синхронизироваться.
Отдельный замер DIRECT после синхронизации передал часы (7,0, 138×28)
и стрелку (454,76, 330×288) как две зоны, 50 порций, 22 318 байт за 0,412 с.
Designer отрисовал те же две зоны при постепенном показе и принял обновление
при выключенном Progressive. Клик из Designer открыл страницу TPMS/GPS.
После теста плата вернулась в FULL/2/Dirty с буферным RLE и страницей Setup.
Ревизия сохранённого проекта совпала с исходной.

Тесты: 389 JS, два NaWServer TCP-теста на медленном транспорте (точная длина
и EOF), сборки S3 и Designer Windows, проверка реального кадра Designer.
Протокол проверен на плате и в Designer. Физическое качество изображения
отдельно не оценивалось.
