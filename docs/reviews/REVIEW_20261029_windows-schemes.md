# Четыре цветовые схемы Windows — 2026-10-29

## Реализация

Первый проигрыватель с документацией зафиксирован коммитом `2dfe4bd`.
Следующий этап добавляет только Windows-оформление: Светлая, Кремовая,
Изумрудная, Тёмная по базовым токенам TechnicalShell. Общий runtime, ABI,
аппаратная демка и адаптеры S3 не менялись. Плата не опрашивалась.

JSON-палитры компилируются общими кодеками. Приложение использует существующие
`parse_project`, `StyleRuntime`, `StyleValue::replace` и статические ресурсы
`StyleService`. Страницы подключают роли через обычные ссылки
`global-static:ui.*` и селекторы частей/состояний. Распознавания компонентов по
демо-ID в движке и замены RGB по совпадению нет. Проект не переписывается.

Палитры хранятся как данные; CSS/код оболочки не копировались. Цвет текста
кнопок вычисляется контрастным. Ползунок выключенного switch не перекрывается
непрозрачным индикатором: штатная прозрачность состояния LVGL сохранена.

## Проверки

- MSVC x64 Release / LVGL 9.6.0: сборка успешна.
- JS: 306 тестов, включая компиляцию/обратимость всех палитр, исходные цвета,
  контраст основных текстов/статусбара/обычных и нажатых кнопок, отказ на неверных данных.
- Настоящий LVGL в скрытом Win32-процессе: четыре схемы, фактические цвета
  фона/текста/дуги, нейтральное off-состояние switch, неизменные bounds и instance IDs.
- Переключение сохраняет вкладку, 42.5 km/h и счётчик 12345. Проверены cache/retain,
  возврат на страницу с актуальными цветами, reload, ошибочная схема и плохой файл.
- Проверены штатные отметки настоящего Win32-меню и ровно один выбранный пункт.
- Выбор сохранён в отдельный временный settings-файл и восстановлен новым
  скрытым процессом без аргумента `--scheme`.
- Тест проверяет `IsWindowVisible == false` и отсутствие foreground у своего
  окна. Физический ввод не отправляется. Ранее работавшее окно не останавливалось;
  новая сборка использует отдельный ignored `local/windows-player`.
- Снимки через `lv_snapshot_take` экспортированы без участия рабочего стола,
  просмотрены и сохранены в документации. Геометрия 800×480 одинакова во всех схемах.

## Границы

Это Windows-прототип цветовых схем. Профили плотности/формы и общий формат
проектных тем пока не добавлены. Системная рамка/меню Windows оформляются ОС.
Для тематизации чужой страницы нужны явные ссылки на роли; локальные свойства
их перекрывают, а `copy/merge` остаются снимками. Нативное рисование с собственными
константами цвета автоматически не меняется. Тест не нажимает меню мышью и не
активирует приложение, поскольку владелец продолжает работать на компьютере.
