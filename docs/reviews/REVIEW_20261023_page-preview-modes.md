# Пассивный выбор страницы и два режима предпросмотра

Дата: 2026-10-23. Требование владельца: выбор страницы не переключает LCD, автоприменение работает после правок; отдельный показ и показ в настоящем контейнере доступны явно.

## Реализация

- Контроллер сравнивает снимки документа вместе с ID страницы. Другая выбранная страница не считается правкой. При уходе со страницы, смене режима, внешнем чтении и изменении автоприменения очередь отменяется, в том числе перед выполнением отложенного микрозадания. Уже отправленная операция завершается обычным образом.
- `modules/composition/page-preview.js` использует существующий `projectCompositionGraph`; отдельного графа/вида страниц или нового MCU API нет. Выбор места вставки общий для браузера и аппаратной кнопки. Реальные пути ограничены 32 вариантами и действующим пределом глубины.
- Для просмотра в контейнере временная копия получает нужные `view.initial` вдоль пути. Исходные размеры, политики, биндинги и события сохраняются. Выделение компонентов в браузере относится к экземпляру редактируемой страницы, даже при одинаковых локальных ID у родителей и детей.
- Для отдельного показа страницы меньшего размера используется временная корневая страница LCD с обычным `view`, `sizing: design` и прокруткой. Это та же композиция и тот же `ProjectClient.preview`, без дублирования логики загрузки. Обёртка входит в обычные лимиты композиции.
- S3 объявляет разрешение действующего LVGL display через `capabilities.display`. Со старой прошивкой берётся размер стартовой страницы проекта. NTP не менялся.
