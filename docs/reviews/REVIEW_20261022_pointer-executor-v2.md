# Проверка исполнителя ABI v2

Дата: 2026-10-22. Работа выполнена в lvgl-cbor; прошивка на плату не записывалась.

## Изменение

Структуры Method/WidgetMethod, универсальные Arguments/WidgetArguments, отдельные valid-функции, поиск пересечений свойств и сортировка фаз на МК удалены. Генераторы создают типизированные массивы, содержащие исключительно указатели. ABI v2 имеет плотные индексы внутри сигнатур. Группировка стандартных виджетов общая: 32 операции, 14 сигнатур. Стили: 138 операций, 28 сигнатур.

PC-кодеки выполняют семантические проверки и сохраняют порядок исполнения в CBOR. Проверки целостности чтения, доступности индекса/фабрики/ресурса, лимитов хранения и ABI остались в загрузчике. Обработчики значений на МК не проверяют допустимые диапазоны и сочетания свойств.

Добавлена регистрация NativeWidget во время работы через приложение-владелец WidgetRegistry. Экземпляры удерживают свою регистрацию и заимствованные буферы. Каталог с описаниями отделён от массивов вызовов и используется ПК.

## Результаты

- `npm run contract:check`: производные C++/JS/документация соответствуют контрактам.
- `npm test`: 208 тестов прошли.
- `tools/test_native.ps1`: три набора на настоящих LVGL 9.6/TinyCBOR прошли; стандартные виджеты, Grid/Flex, изоляция экземпляров, замена и удаление, общий сервис стилей.
- Нативный тест порядка: Textarea с max_length=3 получает `abc` из `abcdef`; Slider с новым диапазоном -200…200 получает 150, а не значение, ограниченное исходным диапазоном.
- `example:meter` зарегистрирован после создания ScreenRuntime. Проверены общая числовая сигнатура, уникальная `(int32_t, text)`, сохранность заимствованного текста после уничтожения входного буфера, удаление регистрации при живом объекте, отказ нового создания и отказ при другом ABI.
- `check_native_extensions.mjs`: настоящий JSON capabilities, опубликованный C++-реестром, использован ПК для обратного преобразования и идентичной повторной компиляции пакета расширения.
- `npm run build` и `pack_assets.mjs`: браузерный пакет ABI v2 собран и упакован.
- `tools/build_s3.ps1`: прошивка ESP32-S3 собрана. Физический экран и запись на плату в этой задаче не проверялись.

## Размеры таблиц

Проверено `xtensa-esp32s3-elf-nm -S --size-sort -C` по ELF до и после изменения. Предыдущий ELF содержал дескрипторы v1; новый — массивы указателей v2. Размеры только таблиц, без строк, кода, capabilities и памяти экземпляров:

| Таблица | До, байт | После, байт |
|---|---:|---:|
| Методы стилей | 3864 | 552 |
| Методы виджетов | 640 | 128 |
| Фабрики | 144 | 48 |
| Всего | 4648 | 728 |

Экономия самих таблиц — 3920 байт. Скорость исполнения не измерялась; эти числа не являются оценкой общего RAM-потребления или ускорения.

Локальные доказательства: `local/dispatch-before-symbols.txt`, `local/dispatch-after-symbols.txt`, `local/dispatch-table-sizes.json`, `local/pointer-js-tests.log`, `local/pointer-native-tests.log`, `local/pointer-web-build.log`, `local/pointer-s3-build-final.log`.

Ограничение расширений: поддержаны C++-реестр, публикация контракта и программные кодеки. Произвольная визуальная форма редактора для нового нативного виджета автоматически не строится. Изменение ABI компонента требует нового идентификатора ABI его регистрации. Регистрация связывает существующий машинный код, а не загружает его из пакета.
