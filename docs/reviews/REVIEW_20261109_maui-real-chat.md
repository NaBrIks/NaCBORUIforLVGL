# Реальный чат MAUI через SPLA/OpenRouter — 2026-11-09

Продолжение [первой приёмки](REVIEW_20261108_maui-designer.md).

После разрешения владельца существующий ключ перенесён из защищённых настроек
демки в штатный SecureStorage MAUI на Windows и Android-эмуляторе. Значение ключа
не записывалось в исходники, инструкции, APK или журналы. Сохранение выполнялось
через форму приложения; после перезапуска обе платформы прочитали сохранённый ключ.
Физический телефон пока не участвовал в проверке.

## Результат

Обе платформы выполнили настоящий запрос к выбранной модели `qwen/qwen3.8-27b`
через OpenRouter и существующий SPLA OpenAI-compatible transport. Модель вызвала
MCP `get_project_status`, получила статус настоящего Windows LVGL и назвала
проект/текущий экран. Во втором сообщении без инструментов модель точно повторила
маркер из первого: история передаётся между пользовательскими отправками.

Это были запросы только на чтение. Проект, стили и данные target не менялись.
Ревизия проекта после проверки совпадает с исходной. Ответы отображаются Markdown,
в журнале виден успешный инструмент. Исходники SPLA сохранены без изменений.

## Исправление, найденное реальной проверкой

Первый Android LLM-запрос завершился `Android.OS.NetworkOnMainThreadException`.
Ранее работающие подключение MCP/кадр и тесты HttpMessageHandler этого не выявляли.
В DesignerSessionAdapter запуск сетевых операций SPLA перенесён в фоновую Task:
подключение, чат, каталог моделей и получение кадра. Обновление UI по-прежнему
проходит через диспетчер. Повторный Android запрос успешно прошёл весь цикл
модель → MCP → модель, затем проверено следующее сообщение с контекстом.

Windows и ARM64/x64 Android пересобраны. Подготовлены обновлённые debug-signed
APK с включёнными managed assemblies. Они не содержат ключ и исключены из Git;
ключ уже установлен только в SecureStorage проверенных экземпляров приложения.
На новом телефоне ключ потребуется ввести отдельно.

Журналы, скриншоты, SHA256 APK и исходные измерения находятся только в ignored
`local/maui_designer`. Прямой MCU HTTP MCP и offline LVGL renderer телефона
остаются отдельными задачами, как и до этой проверки. Плата не прошивалась.

В приёмке длинного ответа также исправлена автопрокрутка чата: программная
прокрутка теперь без smooth-анимации. Промежуточные scroll events анимации
ранее ошибочно отключали слежение за последним сообщением. Ручная прокрутка
вверх сохраняет возможность читать историю.
