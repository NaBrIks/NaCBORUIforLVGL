# Приёмка компоновки и CBOR demo speed

Дата: 2026-10-28. Изменения относятся к S3-примеру, общему браузерному приёму
данных и read-only проекции биндингов. Ядро и протоколы экранов/стилей не менялись.

## Подтверждённые проверки на ПК

- 301 JS-тест, включая runtime-снимки, гонки bootstrap/WS, disconnect/reset и
  отсутствие изменений авторской модели; production build, contract:check — PASS.
- 8 MCP-тестов — PASS.
- Настоящий LVGL 9.6.0/MSVC загрузил поставляемый проект с глобальными стилями,
  оболочкой и всеми тремя страницами. Область контейнера 800×408; проверены
  координаты всех видимых потомков, включая внутренние нативные объекты,
  отсутствие пересечения соседних компонентов и нулевое переполнение контейнера.
- Растровые кадры LVGL просмотрены для dashboard/radar/trip. Стрелка, шкала,
  цифровое значение, единицы, подписи радара и индикаторов видны целиком.
- В реальном ScreenRuntime/DataRegistry проверено применение дробных значений
  43.125 и 179.625 через биндинг к нативному спидометру без округления стрелки.
- Модель скорости: пределы, непрерывность 25 Гц, экстремумы и пропуск задержанных
  отсчётов — PASS.
- Общий адаптер CBOR: только committed-снимки, начальная неизвестность,
  объединение изменений, повтор при backpressure, stale, размер и teardown — PASS.
- ESP-IDF 5.5.6 / S3 build — PASS; static RAM 84492 Б, Flash 1958741 Б.

## Аппаратная и браузерная проверка

На идентифицированную S3 записаны приложение и проектный SPIFFS, оба региона
проверены по хешам; таблица, bootloader и NVS сохранены. Размер приложения
1959152 Б, SHA256 `ce7860a2a20ed4755d99f4ef8476a787995bd770d895a382f7f284fa76cdfbcc`.

- Сохранённый entry — shell; страницы dashboard/radar/trip имеют 800×408.
- Реальный `/ws`: за 4.2 с получены 24 события скорости с дробными значениями;
  последовательность возрастает, пределы и приращения соответствуют модели.
  После закрытия клиента счётчик продолжает расти.
- HTTP и ACK всех трёх WS, затем четыре группы проверок вложенной навигации,
  cache/retain/release и заглушки цикла — PASS. Boot стабилен, bindingErrors,
  queueDropped и rejectedEvents равны нулю, lastError пуст.
- Встроенный редактор загрузил сохранённый проект. Во всех трёх страницах
  browser content имеет clientWidth/scrollWidth=800, clientHeight/scrollHeight=408.
  Время, IP и текущий аргумент reading_number обновляются по CBOR-событиям.
- При включённом автоприменении поступление значений не переводит MCU в preview
  и не меняет ревизию сохранённого проекта. Настройка после проверки возвращена.
- Консоль браузера: без ошибок/предупреждений; адрес вкладки редактора оставался
  прежним. Самопроизвольный переход на другой сайт не воспроизведён.
- На двух кадрах USB-камеры видны разные положения стрелки и показания 1 и 3,
  статус синхронизации и IP. Экспозиция/фокус камеры восстановлены. Часть LCD вне
  кадра; полная геометрия подтверждена отдельной LVGL-отрисовкой и браузером.
- МК оставлен на сохранённом главном экране, preview=false. Диагностические
  команды навигации не считаются проверкой физических нажатий touch.
- Дополнительный обычный перезапуск изменил boot_id; entry shell, ревизия
  сохранённого проекта и размеры всех трёх страниц 800×408 сохранились.
  Вебка автоматически переподключилась и возобновила живые данные без reload.
  Остаток стека HTTP worker после приёмки — 5828 Б.

Частные адреса, идентификаторы, исходные логи и снимки хранятся только в ignored
`local/`. NTP-настройки, соседние приложения и Bluetooth не изменялись.
