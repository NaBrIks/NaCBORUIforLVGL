# Проверка сетевой синхронизации времени

Дата: 2026-10-23. Проверено на ESP32-S3 с ESP-IDF 5.4 и штатным SNTP.

## Метод

Проверены запуск SNTP после получения IP, DNS с самого контроллера, обычный HTTP-запрос и независимые UDP-запросы NTP. Сравнение с другим клиентом сети используется только как контроль: оно не подтверждает доступ контроллера.

IP-адрес и успешный DNS не гарантируют доступ в интернет. Перенаправление обычного HTTP-запроса на страницу авторизации указывает на ограничение доступа. При этом SNTP может оставаться в состоянии `syncing` без ответа. Проверка исходящих портов и отдельных сокетов позволяет отличить сетевую недоступность от ошибки клиента.

## Результат

После предоставления контроллеру интернет-доступа штатный SNTP синхронизировался без изменения реализации и списка серверов. После загрузки чистой прошивки синхронизация повторилась автоматически. Через API подтверждены `syncState=synchronized`, ход секунд, пустой `error` и `bindingErrors=0`; часы и статус проверены на LCD.

Временная диагностика удалена из рабочей прошивки. Сохранённый UI-проект не изменён; файловая система и NVS не переписывались. Параметры конкретной сети, устройства, журналов и допуска не входят в публичную документацию.
