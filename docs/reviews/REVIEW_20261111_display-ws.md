# Приёмка WebSocket-предпросмотра, 11.11.2026

S3 7″, 800×480 RGB565, DIRECT/2/Dirty, буферный RLE. На одной прошивке и
одной странице Setup сравнивались штатное автообновление HTTP и ожидание
следующей ревизии по уже открытому WebSocket. Начало секунды оценивалось по
середине между двумя чтениями `system.clock/unixSeconds` через API S3.
Конец — первое изменение пикселей часов на видимом canvas Windows Designer.
Отрицательные единичные отсчёты −3 и −19 мс укладываются в погрешность
опроса и не означают, что кадр пришёл до смены секунды.

| Транспорт | Медиана | Максимум | Отмеченные смены секунд |
|---|---:|---:|---:|
| HTTP | 615 мс | 858 мс | 6 из 8 |
| WS | 133 мс | 200 мс | 8 из 8 |

Это измерение поведения двух способов обновления, включая ожидание опроса
HTTP. На Radar с крупной анимированной областью предварительный проход
не дал достаточно пар для устойчивого сравнения WS. Позиции двух чисел и
шкалы на Setup совпали во всех замерах.

При отдельном тесте начатая передача прервалась после 13 707 байт старой
сцены. По тому же соединению после `cancel` пришло 100 711 байт новой сцены.
Максимальный бинарный фрагмент в этом прогоне — 1024 байта.

Проверены Windows Designer, реальные ответы S3 и 389 тестов общего JS-кодека.
Изображение физической панели отдельно не оценивалось. После замера
восстановлен FULL/2/Dirty с буферным RLE и открыта Setup. Проект не изменился.

## Полный кадр после увеличения фрагмента

На той же Setup в DIRECT/2/Dirty с буферным RLE полный кадр весил около
72 КБ во всех прогонах. Медиана трёх полных передач по WS снизилась с
2,92 до 0,71 с. HTTP на итоговой прошивке занял 0,65 с. LVF2 и RLE
одинаковы для обоих транспортов.

У исходной реализации один сетевой блок клиента заполнялся 1 КиБ, а
следующий отправлялся после очередного прохода LVGL. Новая реализация
упаковывает до 4092 байт LVF2 в тот же блок 4 КиБ и сохраняет один
подготовленный фрагмент на время ожидания. Полной копии кадра нет.

В Designer проверены оба полноразмерных кадра и смена подписей
«Используется HTTP» и «Используется WS». Окно оставлено на HTTP.
S3 оставлена в DIRECT/2/Dirty с буферным RLE. DIRECT также установлен
в качестве исходного режима при отсутствии сохранённой настройки.
