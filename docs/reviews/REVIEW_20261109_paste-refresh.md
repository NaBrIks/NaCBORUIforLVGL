# Вставка изображений и обновление композиции без сброса — 2026-11-09

> Результаты MCP в этом отчёте относятся к прежней реализации.
> Актуальные способы подключения описаны в [руководстве MCP](../readme_mcp_ru.md).


В MAUI чат добавлена вставка изображений из буфера через обычный paste event
WebView (Ctrl+V в поле запроса). Изображение становится тем же вложением, что
и выбранный файл; введённый текст остаётся. Обычный текст вставляется штатно.
Общие пределы: 8 вложений, до 8 МБ на изображение. Ошибки доступны по ⓘ.
Проверено через ClipboardEvent/DataTransfer настоящего WebView и JS→.NET:
PNG появился во вложениях, декодирован, черновик не изменился. Системный буфер
владельца для проверки не перезаписывался.

Причина сброса страницы была в операции обновления: после сохранения MCP раньше
предлагал загрузить entry заново. Новая композиция закономерно выбирала defaults.
Теперь ProjectService::refresh и POST /api/project?action=refresh обновляют
текущий корень с активной вложенной навигацией. Состояние хранится по пути
локальных ID контейнеров и именам выбранных страниц; instance ID не используется
для сопоставления. Имена демки и номера вкладок в реализации отсутствуют.

MCP предоставляет refresh_project_display; save_project/write_project_document
также принимают refresh:true для сохранения и обновления одним вызовом.
По умолчанию сохранение остаётся невизуальным. show/preview — явный новый показ
с начальными страницами. Если сохранение прошло, а refresh нет, ответ сообщает
saved и refreshError: повторять запись не нужно. Это не сохранение всего состояния
LVGL: не связанные с источниками значения/прокрутка объектов могут сброситься.

Удалённые маршруты переходят к новым defaults. Для другого проекта старые пути
не применяются. Неуспешное создание нового корня оставляет прежний экран.

Проверены native composition/project/screen tests: глубина 4, повторные экземпляры
с одинаковыми локальными ID, разные выбранные листья, реальное изменение узла,
удаление/переименование контейнера, смена проекта, ошибка загрузки, явный show.
JS/MCP проверки прошли. На настоящем Windows LVGL через MCP сохранён неизменённый
документ открытой дочерней страницы с refresh:true, затем выполнен отдельный refresh:
корень и выбранная дочерняя страница сохранились, instance ID сменились,
ревизия проекта осталась прежней. Исходные замеры только в ignored local.

На дату отчёта Windows проигрыватель и прежний посредник были запущены; MAUI оставлен в одном
экземпляре с новым вводом. SDK/кодеки/ProjectService общие. MCU HTTP-адаптер изменён,
но аппаратная сборка/прошивка в этой проверке не выполнялась. Плата не тронута.
