# Windows LVGL player — проверка 2026-10-29

> Результаты MCP в этом отчёте относятся к прежней реализации.
> Актуальные способы подключения описаны в [руководстве MCP](../readme_mcp_ru.md).


## Результат

Добавлен независимый MIT-пример `examples/windows_player`: настоящий LVGL 9.6.0
Win32 backend, существующие C++ сервисы и общие JS-кодеки. JSON компилируется в
CBOR на ПК; C++ runtime, биндинги и события не дублируются. Новый ABI или JSON
parser в C++ не добавлены. S3 не опрашивалась, не сбрасывалась и не прошивалась;
её исходники/проект/FS не изменены. Настройки NTP не затронуты.

## Проверено

| Проверка | Результат |
| --- | --- |
| MSVC x64 Release, реальный LVGL 9.6.0 / TinyCBOR | Сборка успешна |
| Общие тесты JavaScript | 303 PASS, включая два новых теста desktop loader |
| `npm run contract:check` | PASS; прежние style v2 / screen v3 |
| `npm run build` | Сборка редактора успешна |
| `npm run player:test` | PASS; настоящие Win32 окна и C++ runtime |
| SeMaps renderer / `semaps check` | `no problems found`; карта сохранена, `unsaved=[]` |

Оконная интеграционная проверка запускает launcher с путём, содержащим пробелы
и кириллицу. Проверены JSON/CBOR, числовая/форматированная привязка, публикация
CBOR-значений, writable-источник, зарегистрированные действия, навигация и
удержание дочерней страницы. При возврате доступно последнее значение источника.
Проверены watcher (включая сохранение повреждённого JSON и последующее исправление),
отказ на повреждённом CBOR/неизвестном ресурсе корня с сохранением прежнего экрана,
штатная заглушка ошибочной дочерней страницы, новое разрешение и завершение.
После same-size reload сохраняются данные приложения и правильный `CHECKED`.

Визуально просмотрена настоящая Windows-композиция 800×480 с DPI-масштабированием:
статусная строка, дуга скорости, подписи, переключатель и нижнее меню помещаются.
Мышью проверены действие `Add 1`, остановка генератора переключателем (значение
не менялось несколько секунд), переход Details, действие `Add 10` и возврат:
счётчик и последнее значение скорости сохранились. Ctrl+O открывает системный
диалог выбора; F5 перечитывает файл. Последняя дополнительная визуальная проверка
после исправления константы состояния остановлена владельцем клавишей Esc;
восстановление состояния после исправления подтверждено интеграционным тестом.

При приёмке устранены два дефекта desktop-примера: скрытый консольный запуск
больше не скрывает LVGL-окно; обе границы короткого щелчка читаются LVGL немедленно,
чтобы не терять down/up между тиками драйвера. Значение `CHECKED` в демке исправлено
по контракту LVGL 9.6 (4); тест проверяет его соответствие и применение после reload.

## Границы

- Работа с файлами и локальным stdio; HTTP/WS-сервер редактора на ПК пока не реализован.
- JSON требует Node launcher; отдельный Node runtime в поставку не включён.
- Windows-приложение регистрирует свои источники, действия и ресурсы. S3 native
  widgets автоматически не подменяются: переносимую реализацию нужно зарегистрировать.
- Часы — системные Windows. Данные скорости — явно обозначенная автономная демка.
- Изменение разрешения создаёт новую desktop-сессию с новыми демоданными;
  обычное перечитывание при прежнем размере сохраняет реестр приложения.
- Сборки, пакеты и частные журналы находятся только в ignored `local/` / OS temp.
  Исходные пользовательские документы не перезаписываются.
