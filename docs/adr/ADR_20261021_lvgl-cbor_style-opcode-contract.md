# Числовые инструкции стилей и отдельный контракт

Статус: принято для первого опыта 2026-10-21 по прямому запросу владельца.

Дополняет ADR_20261020_lvgl-cbor_runtime-symbolic-names.md: его запрет числового словаря не распространяется на разрешённую теперь индексацию методов стилей. Имена прикладных полей, источников, привязок, стилей и ресурсов остаются символьными.

Используется contracts/style-api-v1.json как единственный фиксированный индекс shared-методов и сигнатур LVGL 9.4.0. У каждого семейства отдельная нумерация. В текущем опыте младший байт — сквозной индекс метода shared, старший — ожидаемая сигнатура. Таблица дескрипторов одна на семейство, вызовы выполняются через правильные типизированные обёртки.

Преобразования JSON↔CBOR находятся в packages/style-codec и не зависят от Vue. C++-дескрипторы и JS-контракт генерируются из одного JSON. Сортировка HTML не перенумеровывает wire-контракт.

Две области именованных стилей: global и screen. Замена полная, адрес слота стабильный. Композиция: copy → merge в указанном порядке → собственные свойства. Живой зависимости от скопированных источников нет.

Сравнение отдельных таблиц сигнатур и варианта без старшего байта сохраняется в readme_style_protocol_ru.md. Измерение выигрыша и окончательный формат следующих версий остаются открытыми.
