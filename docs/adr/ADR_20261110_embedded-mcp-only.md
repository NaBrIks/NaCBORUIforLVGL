# ADR: MCP только внутри целевого приложения

Статус: принято по прямому указанию владельца 10.11.2026.

Решение supersedes части прежних ADR о посреднике MCP на ПК. Принятые ранее
контракты ProjectService, DataRegistry, JSON/CBOR и разделение preview/save
сохраняют силу; старые утверждения о посредниках больше не являются направлением.

MCP должен исполняться внутри целевой демки или прошивки. Listener предоставляет
NaWServer, обработчики используют существующие нативные сервисы и ограничения.
Отдельные процессы-посредники, HTTP gateway и запасной сервер не допускаются.
MAUI-конструктор сохраняет SPLA HTTP MCP-клиент для совместимого target.

На дату решения существовали только HTTP/WS API и редактор. Встроенный
Windows MCP и отдельное разрешение на opt-in endpoint Windows Designer
зафиксированы в [текущем руководстве](../readme_mcp_ru.md).
