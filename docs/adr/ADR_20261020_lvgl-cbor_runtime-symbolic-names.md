# ADR: runtime-экраны и символьные имена

Дата: 2026-10-20.
Статус: принято в части явно заданного владельцем направления.

## Контекст

Нужно загружать новые экраны LVGL без перепрошивки и связывать элементы с данными приложения. Проект размещён в `../lvgl-cbor`.

## Решение

Описание передаётся в CBOR. Имена полей и сущностей остаются символьными UTF-8. Числовые коды ключей и словари имён не вводятся. Создание объектов LVGL выполняет собственный исполнитель. Название проекта — lvgl-cbor.

## Последствия

Схему описания и контракт биндингов нужно документировать отдельно. Новое описание компонует доступные возможности прошивки. Этот ADR не выбирает версии библиотек, лицензию проекта, язык API или конкретный способ доставки.
