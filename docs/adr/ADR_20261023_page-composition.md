# ADR: вложенные экземпляры страниц

Статус: принято владельцем 2026-10-23.

## Решение

Страница остаётся единым описанием UI, биндингов и событий. Её можно загрузить отдельно или создать внутри обычного узла другой страницы. Типов «оболочка» и «дочерняя страница» в переносимом контракте нет. Экземпляры образуют дерево владения; описания проекта образуют граф допустимых вставок.

Узел с `view` объявляет допустимые страницы, начальную страницу, политику хранения каждой страницы и способ определения размеров. Событие `navigate` выбирает страницу локального контейнера. Имена страниц, узлов и источников остаются символическими в документе. Исполняемые переходы разрешаются один раз в локальные индексы; экземпляр получает числовой идентификатор.

`ScreenRuntime` владеет дочерними `ScreenRuntime`, используя тот же cursor executor screen v3, общий `StyleService` и приложение-владельца `DataRegistry`. Отдельного интерпретатора экранов нет. Дополнительные метаданные композиции версионируются независимо от команд screen v3; старые документы без композиции сохраняют своё представление.

Политики: **Освобождать**, **Кэшировать**, **Удерживать**. Создание всегда по требованию. Неактивные экземпляры приостанавливают биндинги, события и поддерживающие активацию нативные компоненты. Возврат применяет последний снимок источника. Историю измерений и работу оборудования определяет приложение, а не присутствие страницы на дисплее.

Дочерние экземпляры завершаются до удаления объектов родителя. Простые общие пределы ограничивают глубину, число экземпляров и неактивный кэш. Удерживаемые страницы не вытесняются; при исчерпании предела переход показывает ошибку. Автоматического управления памятью по свободной куче нет.

При ошибке выбранная вкладка сохраняется, содержимое заменяется красным крестом. Явная загрузка или preview проекта пересоздаёт всю композицию. Сохранение проекта по-прежнему не переключает текущий экран. Кэш по ревизиям не вводится.

Размеры: заполнение контейнера либо проектный размер страницы. Прокрутку определяют обычные свойства LVGL. Редактор показывает вложенный просмотр в заданном viewport и граф связей, полученный из тех же описаний; отдельной копии графа в проекте нет.

## Применение

Строка NTP-времени/IP и нижняя навигация — обычная страница примера. Источники `system.clock` и `system.network` принадлежат приложению ESP-IDF, а не UI-ядру. Общий редактор не содержит специальных форм или ветвей для этой оболочки.

## Следствия

- Повторное использование страницы не требует глобально уникальных имён её объектов.
- Непрерывный график требует ограниченной истории в источнике; пауза UI не восстанавливает потерянные измерения сама.
- Удержание сохраняет состояние виджета ценой памяти; сохранение прикладного состояния между удалениями остаётся обязанностью приложения.
- Браузерный preview проверяет компоновку и переходы приблизительно; аппаратное исполнение и приёмка проверяются отдельно.
