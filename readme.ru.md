# NaCBORUIforLVGL

[English](README.md) · Русский

**CBOR-based UI definitions for LVGL** — описания интерфейсов LVGL на основе CBOR.

Модульный редактор и исполняемое ядро динамических интерфейсов LVGL: документы JSON/CBOR, общие стили, биндинги данных, события и вложенные страницы.

Создавайте проект в браузере, проверяйте на подключённом устройстве и сохраняйте отдельной командой. Новые описания экранов загружаются без пересборки прошивки. Приложение регистрирует доступные редактору источники данных, действия и нативные компоненты.

Имя репозитория: `NaCBORUIforLVGL`.

## Возможности

- Документ проекта целиком: экраны, общие стили и стартовый экран.
- Двусторонние JSON/CBOR-кодеки, импорт и экспорт CSS для поддерживаемых свойств.
- Типизированные символьные источники и действия; биндинги и события принадлежат экрану.
- Вложенные страницы с политиками освобождения, кэширования и удержания.
- Каталог возможностей устройства и подхват изменений проекта через WebSocket.
- Предпросмотр отделён от сохранения; подключение и выбор страницы не меняют экран устройства.
- Опциональный MCP-адаптер на ПК использует существующий API устройства и общие кодеки.
- Браузерный симулятор, Windows-проигрыватель на настоящем LVGL и пример для ESP32-S3.

## Запуск редактора

Нужны Node.js 20.19+ или 22.12+ и npm.

```sh
npm ci
npm run sim
```

В Windows также можно запустить `RunSimulator.cmd`. Браузерный предпросмотр приближает компоновку средствами CSS и **не исполняет LVGL**. Поведение аппаратного экрана проверяется на устройстве.

Для **настоящего LVGL** на ПК соберите [Windows-проигрыватель](docs/readme_windows_player_ru.md) и запустите `npm run player -- interface.json` или `.cbor`. Он использует те же CBOR runtime, биндинги и события. В меню приложения есть светлая, кремовая, изумрудная и тёмная схемы; смена общих стилей сохраняет страницы и данные. `--watch` перечитывает сохранённый файл. Нужны C++ Build Tools, CMake и указанные исходники LVGL/TinyCBOR; ESP-IDF и плата не требуются.

```sh
npm test
npm run contract:check
npm run build
```

Опциональный MCP-адаптер имеет отдельные зависимости и тесты:

```sh
npm --prefix integrations/mcp ci
npm --prefix integrations/mcp test
```

## Архитектура и переносимость

Ядро C++ находится в `include/lvgl_cbor` и `src`, переиспользуемые JavaScript-кодеки — в `packages`. Драйверы платы, сеть, получение данных и хранилища подключаются приложением. Ядро не привязано к ESP32; готовый аппаратный пример использует ESP32-S3, ESP-IDF и отдельные соседние проекты.

HTTP/WebSocket-сервер примера — **NaWServer** (ранее ESP32-yaidfws), ожидается в соседней папке `NaWServer`. Репозиторий NaWServer пока приватный: для сборки демки нужен доступ. Браузерный симулятор и самостоятельное ядро его не требуют. Перед сборкой прошивки прочитайте [руководство примера](examples/s3_style_lab/README.md).

Целевая версия — **LVGL 9.6.0**. Экраны используют курсорный ABI v3, стили — ABI v2. JSON — редактируемый исходник, CBOR — представление для устройства. Имена данных приложения остаются символьными строками UTF-8.

Идентификаторы `lvgl_cbor`, `LVGL_CBOR_*`, `@lvgl-cbor/*` и ключи браузерных черновиков сохранены для совместимости. Переименование проекта не меняет ABI и форматы передачи.
