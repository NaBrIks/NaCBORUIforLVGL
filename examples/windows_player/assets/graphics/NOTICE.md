# Graphics gallery assets

Owned procedural samples are MIT, copyright 2026 Oleg Kozhevnikov:
`sample.png`, `sample.jpg`, `sample.bmp`, `sample.gif`, the generated LVGL BIN,
the shared RGB565 checkerboard (`checker.png` is its editable source),
the 21-path multi-color `landscape.svg`,
and raw RGB565/RGB888/XRGB8888/ARGB8888/A8/I4 buffers. They are generated by
`../../tools/generate_graphics_assets.py` using Pillow 12.2.0. The GIF has eight
120 ms frames; it is a real LVGL GIF widget, not browser animation.

The BIN is the existing LVGL9 binary image header (12 bytes) plus RGB565 pixels,
matching the pinned LVGLImage.py header layout. No project-specific image format
is introduced. Generated bytes are embedded by `src/graphics_assets.generated.hpp`;
`manifest.json` records exact lengths and SHA256. Runtime BMP/BIN reads use LVGL's
bounded memory file driver, independent of local disk paths.

## Tabler icons

`tabler/heart.svg` and `tabler/cloud.svg` come from the official Tabler repository,
pinned to commit ed177a085b652fe04ec4f37ced867c94621e7840:

- https://github.com/tabler/tabler-icons/blob/ed177a085b652fe04ec4f37ced867c94621e7840/icons/outline/heart.svg
- https://github.com/tabler/tabler-icons/blob/ed177a085b652fe04ec4f37ced867c94621e7840/icons/outline/cloud.svg
- https://github.com/tabler/tabler-icons/blob/ed177a085b652fe04ec4f37ced867c94621e7840/LICENSE

Copyright (c) 2020-2026 Paweł Kuna. Full MIT terms are retained in `tabler/LICENSE`.
Original source files remain unchanged. The generated embedded variant removes
editorial comments, changes only width/height to96 and resolves `currentColor`
to a visible teal stroke. LVGL's SVG parser/vector renderer draws the paths;
these SVG files are never rasterized by a browser or by the asset-generation script.
The heart uses arcs; the cloud contains cubic curve commands.

`landscape.svg` is independently generated in this project: layered colored hills,
quadratic/cubic paths, a sun, eight trees, five birds and a house (21 paths).
The script embeds its original SVG bytes; LVGL parses and renders the SVG.
It is not a screenshot or an SVG rasterization generated by Pillow.

## Runtime libraries

LVGL, bundled ThorVG, LodePNG, Tiny JPEG and GIF libraries retain their own
upstream licenses/notices in the selected LVGL dependency. The gallery's MIT
license does not replace those terms. No external JPEG/WebP/FFmpeg runtime is
added by this example. Lottie is not enabled by the gallery profile.
