# Обычный интерфейс и авиационная панель

[English](cockpit.md)

Полный демонстрационный каталог стартует в обычной оболочке с вкладками
TPMS / GPS, Radar, Trip и Setup. Кнопка **FLT** справа внизу заменяет
весь интерфейс авиационной панелью. **STD** на том же месте возвращает
обычную оболочку и выбранную вкладку.

Панель показывает демонстрационное давление и штатный радар. Время и IP
поступают из системных источников. Переключатель **LCD / LED** меняет
оформление показаний давления. Фон, металлические рамки, углубления и
головки винтов собраны из обычных объектов и стилей LVGL. У каждой
головки одинаковая форма и свой угол прорези.

Переключение использует штатные CBOR-страницы, события навигации и
контейнеры. Для подготовки каталога см. [сборку примера](README.md#сборка).

На 7″ S3 проверялась последовательность Radar → FLT → LCD → LED → LCD → STD
через штатный ввод по координатам. STD вернула вкладку Radar. Кадры
LVGL с платы подтвердили смену фона и цвета цифр, а диагностика показала
ноль ошибок биндингов и тот же ID загрузки. Изображение на физической
панели проверяется отдельно.

Нативный тест LVGL проверяет оба направления переключения. Подготовьте
данные командой `node tools/native_widget_fixtures.mjs` и запустите
тест нативных виджетов с каталогом данных и флагом `--interfaces`.
