# Examples

| Example | Purpose | Start here |
| --- | --- | --- |
| [Windows System](windows_player/README.md) | Win32 LVGL player with system metrics, bindings, events and nested pages | Build the player, then run `npm run player` |
| [Windows Graphics](windows_player/README.md#native-graphics-gallery) | The same player with a separate raster, vector and editable canvas project | `npm run player:graphics` after building the player |
| [Waveshare ESP32-S3 Touch LCD 7](s3_style_lab/README.md) | 800×480 RGB/touch hardware demo with the web editor, live display and a simulated dashboard | Build the firmware and provision the bundled project catalog |
| [LilyGO T-Display-S3](lilygo_t_display_s3/README.md) | 320×170 ST7789 example with USB diagnostics and an optional Wi-Fi preview | Build the USB profile first |
| [Native widget](native_widget/README.md) | Portable custom-component registration in an application | Register the sample widget and publish its metadata |

The [screens](screens/) directory contains editable layout samples.
[Common](common/README.md) contains shared example modules.
